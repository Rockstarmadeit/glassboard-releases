# Glassboard

A personal desktop space for daily plans, visual inspiration, mind maps and notes.

**Requires macOS Tahoe 26 or newer.** The download supports Apple Silicon and Intel Macs that can run macOS 26.

## Install

1. Open [the latest release](https://github.com/rockstarmadeit/glassboard-releases/releases/latest) and download the **Glassboard ZIP** for that release.
2. Double-click the ZIP, then drag **Glassboard.app** into **Applications**. Run it from Applications, rather than from inside the ZIP or Downloads.
3. Open Glassboard. This privately shared build is not notarised with Apple. If macOS blocks it because the developer cannot be verified, follow Apple's instructions: try opening it, then go to **System Settings → Privacy & Security → Open Anyway**, and confirm that you want to open Glassboard. [Apple's instructions](https://support.apple.com/en-gb/102445).
4. To keep it in your Dock, right-click its Dock icon and choose **Options → Keep in Dock**. Choose **Open at Login** there if you want it to start with your Mac.

## Your content is yours

Each person starts with a fresh workspace. Notes, maps, photos, collections and preferences are stored on that person's Mac in `~/Library/Application Support/Glassboard`. This download includes no one else's saved content. No shared workspace account is needed.

Drag the empty space in the top bar to move the window. In **Settings**, choose **Desktop** to keep it behind other apps or **Normal** to bring it forward when selected. The default is Desktop.

## Updates

Glassboard checks this repository's signed update feed once an hour while running. When a new version is offered, choose **Install Update** to install and relaunch. You can also use **Glassboard → Check for Updates…**, or **Check for Updates…** from its menu-bar icon. Updating replaces the app, while keeping your saved content.

Publishing changes to code alone does not release an update. The maintainer builds and signs a new app release, then publishes the ZIP and signed `appcast.xml` together. An updater-capable copy (1.9 or later) is needed to receive these updates.

## Start here

- **Home:** today's priority, small steps and quick thoughts; previous days stay saved.
- **Inspiration:** photos, captions, colours, links and collections. Command-V pastes a copied image. Website previews contact the website you save.
- **Mind Map:** connected ideas, layouts, search, themes and export.
- **Notes:** searchable notes, pins and folders.
- **Sidebar + → Personalise sections:** choose section names and Apple-style symbols.
- **Circular history arrow:** Recently Deleted and automatic backups.

Optional AI brainstorming only contacts your configured provider when requested; that provider may charge for API usage. Everything else described above can be used without an AI provider.
